# 个人项目正式选题：班级学生成绩管理

## 一、选题登记

- 题目：班级学生成绩管理
- 一句话描述：教师录入成绩，学生按学号查询，系统自动统计平均分与及格率。
- 业务实体：教师（Teacher）、学生（Student）、成绩记录（ScoreRecord），共 3 个主实体。
- 核心用例：
  1. 教师录入、修改成绩；
  2. 学生按学号查询个人成绩；
  3. 按科目统计平均分与及格率；
  4. 按分数段筛选成绩；
  5. 成绩导出（后续阶段）。
- 技术栈：JavaEE8（javax.servlet.*）、Servlet + JSP + JSTL/EL、JDBC、MySQL 8、Tomcat 9、JDK 8。
- 部署目标：本地 Tomcat 9 + MySQL 8（localhost:8080/class-score），后续可用 Docker 打包部署。

## 二、下一阶段三个开发目标

1. 增加教师/学生登录与角色区分，用 Filter 拦截未登录访问。
2. 完成学生端按学号查询个人成绩单页面。
3. 增加按科目、班级的统计报表（平均分、及格率、分数段分布）。
